# Fiche de test de la borne peinture (10 minutes par client)

Consigne : ne rien expliquer. Donnez la tablette et dites « Vous voulez repeindre une pièce, essayez de savoir quoi acheter ». Observez, notez.

## Scénarios (un par client)
1. Repeindre une chambre de 4 × 3 m en blanc.
2. Repeindre deux portes en satin.
3. Traiter une terrasse en bois de 15 m².
4. Peindre le sol d'un garage.
5. Calculer les litres pour un salon, sans passer par les questions.
6. Peindre un escalier dont vous ne connaissez pas la surface (comptez les marches).
7. Trouver, avec la barre de recherche, de quoi traiter une clôture.
8. Comparer deux peintures pour un mur et choisir la moins chère pour 40 m².
9. Terminer par la liste de courses : l'imprimer ou la retrouver sur votre téléphone.

## À observer
| Question | Réponse |
|---|---|
| Le client trouve-t-il tout seul le bon parcours ? (oui/non, temps) | |
| Une question le fait-il hésiter ? Laquelle ? | |
| Comprend-il « litres à acheter » et « pots conseillés » ? | |
| Choisit-il un produit ? Lequel, et pourquoi ? | |
| Utilise-t-il « Emplacement dans le rayon » ? | |
| Aurait-il appelé un conseiller ? À quel moment ? | |
| A-t-il ajouté une 2e pièce au projet ? | |
| A-t-il cliqué sur « Je ne sais pas » ? À quelle question ? | |
| Les couleurs proposées lui ont-elles suffi ? Une couleur lui a-t-elle manqué ? | |
| A-t-il ajouté du matériel (rouleau, bâche…) à sa liste ? | |
| A-t-il scanné le QR, copié ou imprimé la liste ? Laquelle de ces 3 options ? | |
| A-t-il utilisé la recherche en haut de l'accueil ? Qu'a-t-il tapé ? | |
| A-t-il comparé 2 ou 3 produits ? Quel critère a décidé (prix, rendement, séchage) ? | |
| A-t-il lu « Votre chantier en étapes » (durée, séchage, saison) ? | |
| Le mode « Aa » (lecture facile) l'a-t-il aidé ? | |

## Questions à poser à la fin
1. Sur 10, à quel point la borne vous a aidé ? (note)
2. Qu'est-ce qui était le plus utile ?
3. Qu'est-ce qui manquait ou vous a perdu ?
4. Feriez-vous confiance à la quantité conseillée ?
5. L'utiliseriez-vous en magasin plutôt que d'attendre un conseiller ?

## Après 5 à 10 clients
Notez les 3 problèmes qui reviennent le plus, et l'écran « Analyse » de la borne (parcours abandonnés).
