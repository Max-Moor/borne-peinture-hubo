# Borne peinture Hubo (démo)

Contenu : `index.html` + dossier `img/` (19 planches de photos produits).
Les deux doivent rester ensemble, avec ce dossier `img` à côté de `index.html`.

## Mettre en ligne (GitHub Pages)
1. Créez un dépôt GitHub (ex. `borne-peinture-hubo`).
2. Add file > Upload files : glissez `index.html` ET le dossier `img` entier.
3. Settings > Pages > Branch `main` / `/ (root)` > Save.
4. Le site apparaît à `https://<votre-nom>.github.io/borne-peinture-hubo/`.

## Modifier plus tard
Remplacez `index.html` (même nom) sur GitHub : Add file > Upload files.
Hors Claude, la synchronisation entre appareils (demandes conseiller) est désactivée : la démo reste locale.

## Nouveautés de cette version
- **Couleurs** : seules les couleurs réellement disponibles pour les réponses précédentes sont proposées.
- **« Je ne sais pas »** à la plupart des questions, avec « Comment le savoir ? » (petits tests) et un encadré « Ce que nous avons supposé pour vous ».
- **Escalier** : on compte les marches (0,4 m² par marche, à valider).
- **Liste de courses** : matériel ajoutable, récapitulatif, code QR (téléphone), impression (PC), copier. Reprise de la liste pendant 60 minutes.
- **Comparateur** de 2 ou 3 produits, **plan de chantier** (étapes, durées, séchage, conseils de saison), **recherche libre**, **lecture facile (Aa)**.
- **Démo guidée** (bouton en bas de l'accueil, ~1 min) pour présenter la borne.
- **Analyse** : « Je ne sais pas » par question, matériel ajouté, listes emportées, et couleurs absentes du catalogue (calculé sur le catalogue réel).
